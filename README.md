# Adam Study – Android app (download)

Adam Study helps children aged 3 and up learn everyday English words. A friendly helper shows a picture, says the word, and asks the child to repeat it. Directions are in simple Hebrew.

**Download:** grab the latest `.apk` from [Releases](../../releases/latest).

**Install on Android 8.0 or newer:** open the downloaded file on the phone or tablet, and when asked, allow "Install unknown apps" for your browser or file manager.

This repository holds only the installable app, not its source code.
